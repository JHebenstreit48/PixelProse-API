# What Is C#?

<hr class="dividerSection" />

## C# at a Glance

<hr class="dividerSection" />

<span class="emphasis">C#</span>, pronounced <span class="secondEmphasis">"C-Sharp"</span>, is a modern, <span class="emphasis">object-oriented</span> programming language developed by <span class="emphasis">Microsoft</span> as part of its <span class="emphasis">.NET</span> platform.

It is designed to be both powerful and developer-friendly.

It supports a wide range of application types that run on the <span class="emphasis">.NET Framework</span> and <span class="emphasis">.NET Core</span>, which are now unified under the name <span class="secondEmphasis">.NET</span>.

C# is widely used to build everything from <span class="secondEmphasis">console applications</span> and <span class="secondEmphasis">web services</span> to <span class="emphasis">video games</span> and <span class="secondEmphasis">enterprise systems</span>.

<hr class="dividerSection" />

## Why Use C#?

<hr class="dividerSection" />

<span class="emphasis">C#</span> provides a clear and consistent <span class="emphasis">structure</span> for programs, which makes code easier to maintain and reuse.

It supports modern programming features like <span class="secondEmphasis">asynchronous programming</span>, <span class="secondEmphasis">pattern matching</span>, and strong <span class="emphasis">type safety</span>.

It is versatile and used to create:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Mobile applications</li>
    <li>Desktop applications</li>
    <li>Web applications and services</li>
    <li>Websites</li>
    <li><span class="emphasis">Games</span>, including games built with the <span class="secondEmphasis">Unity</span> engine</li>
    <li>VR applications</li>
    <li>Cloud-native and database applications</li>
  </ul>
</div>

<hr class="dividerSection" />

## Summary

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>C# is a modern, object-oriented language developed by <span class="emphasis">Microsoft</span>.</li>
    <li>It is part of the <span class="emphasis">.NET</span> platform.</li>
    <li>It is versatile enough for <span class="secondEmphasis">games</span>, apps, web services, and enterprise systems.</li>
  </ul>
</div>
