# Choosing Which Project Runs in a Solution

<hr class="dividerSection" />

## Why the Startup Project Matters

<hr class="dividerSection" />

A solution can hold several projects, but the Start button only runs one of them.

That project is called the <span class="emphasis">startup project</span>.

It appears in bold in Solution Explorer.

Starting the program runs the startup project, so a different project can look like nothing happened.

<hr class="dividerSection" />

## Setting the Startup Project

<hr class="dividerSection" />

There are two ways to change it, and both have the same effect:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Right-click the project in <span class="emphasis">Solution Explorer</span> and choose <span class="emphasis">Set as Startup Project</span>.</li>
    <li>Use the startup project dropdown next to the Start button in the toolbar.</li>
  </ul>
</div>

A whole project is chosen, not a single line of code.

After the change, Start runs the <span class="codeSnip">Main</span> method of that project.

  <span class="emphasis">See:</span>

    Visual Studio → Basics → Fundamentals → Solution Explorer

</div>

## Summary

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Only the startup project runs when Start is pressed.</li>
    <li>It is shown in bold in Solution Explorer.</li>
    <li>Set it with a right-click or the toolbar dropdown.</li>
  </ul>
</div>
