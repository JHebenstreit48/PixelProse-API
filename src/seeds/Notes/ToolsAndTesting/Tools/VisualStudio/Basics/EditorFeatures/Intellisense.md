# How Visual Studio Helps You Write Code

<hr class="dividerSection" />

## What IntelliSense Is

<hr class="dividerSection" />

<span class="emphasis">IntelliSense</span> is the box of suggestions that pops up while you type.

It helps you write code faster and with fewer typing mistakes.

<hr class="dividerSection" />

## Completing a Name

<hr class="dividerSection" />

Typing part of a name, such as <span class="codeSnip">Con</span>, shows a list of matching names.

<div class="centeredNumberedList">
  1. **Move to the suggestion**

  <div class="centeredBullet">
    <ul class="diamondBullets fullWidthBullet">
      <li>Use the <span class="emphasis">arrow keys</span> to highlight <span class="codeSnip">Console</span> in the list.</li>
    </ul>
  </div>

  2. **Press Tab**

  <div class="centeredBullet">
    <ul class="diamondBullets fullWidthBullet">
      <li>Visual Studio completes the full name.</li>
    </ul>
  </div>
</div>

Completing a name also fixes its capitalization.

Typing <span class="codeSnip">console</span> with a lowercase c and pressing Tab changes it to <span class="codeSnip">Console</span>.

## Members After the Dot

<hr class="dividerSection" />

Typing a dot after a name, such as <span class="codeSnip">Console.</span>, opens a list of everything inside it.

This list shows the methods and properties that can be used.

Selecting a name shows a short description of what it does.

<div class="xrefBox">
  <span class="emphasis">See:</span>
  <a href="/languages/c-family/c-sharp/basics/core-concepts/operators" target="_blank" rel="noopener noreferrer">
    C# → Basics → Core Concepts → Operators (Dot Operator)
  </a>
</div>

<hr class="dividerSection" />

## Parameter Info and Overloads

<hr class="dividerSection" />

Opening the parentheses after a method, such as <span class="codeSnip">Console.WriteLine(</span>, shows what the method accepts.

Many methods can be called in several ways, and each way is called an <span class="emphasis">overload</span>.

A count in the pop-up shows which overload is displayed, and the up and down arrow keys move through them.

Browsing the overloads shows what kind of value a method accepts, such as a string for text.

<hr class="dividerSection" />

## Summary

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>IntelliSense suggests names as you type, and the arrow keys and Tab complete them.</li>
    <li>Typing a dot lists the members of a class or object.</li>
    <li>Opening parentheses shows the overloads a method accepts.</li>
  </ul>
</div>
