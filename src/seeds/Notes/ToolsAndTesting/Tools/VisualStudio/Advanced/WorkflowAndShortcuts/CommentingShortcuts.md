# Commenting Code Faster in Visual Studio

<hr class="dividerSection" />

## Commenting Out Selected Lines

<hr class="dividerSection" />

Visual Studio can comment out many lines at once.

Select the lines, then use either the toolbar or the keyboard.

<table class="notesTable">
  <thead>
    <tr class="tableHeader">
      <th class="tableCellHeader">Action</th>
      <th class="tableCellHeader">Shortcut</th>
    </tr>
  </thead>
  <tbody>
    <tr class="tableRow">
      <td class="tableCell">Comment out the selected lines</td>
      <td class="tableCell"><span class="emphasis">Ctrl + K</span>, then <span class="emphasis">Ctrl + C</span></td>
    </tr>
    <tr class="tableRow">
      <td class="tableCell">Uncomment the selected lines</td>
      <td class="tableCell"><span class="emphasis">Ctrl + K</span>, then <span class="emphasis">Ctrl + U</span></td>
    </tr>
  </tbody>
</table>

The two key presses are made one after the other.

The toolbar has a button for each action.

The <span class="emphasis">Uncomment the selected lines</span> button sits to the right of the <span class="emphasis">Comment out the selected lines</span> button.

Uncommenting restores the lines to what they were before.

<hr class="dividerSection" />

## Why Comment Out Code

<hr class="dividerSection" />

Commenting out code disables it without deleting it.

This is useful when testing a program or when a section is not needed for the moment.

Selecting a block and clicking the button is faster than typing <span class="codeSnip">//</span> in front of every line.
