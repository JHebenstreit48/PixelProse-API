# What Is C++?

<hr class="dividerSection" />

C++ is a powerful, cross-platform programming language used to create high-performance applications.

It is widely used in systems programming, game development, real-time simulations, and applications where performance and memory management are critical.

Originally developed as an extension of the C programming language, C++ was created by <span class="emphasis">Bjarne Stroustrup</span> in 1979 at Bell Labs.

It introduced object-oriented programming features to C and has continued to evolve over the decades.

Modern C++ supports multiple programming paradigms, including:

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Procedural programming</li>
    <li>Object-oriented programming</li>
    <li>Generic programming</li>
    <li>Functional programming</li>
  </ul>
</div>

This flexibility, combined with fine-grained control over system resources, makes C++ a popular choice for performance-critical software.

<hr class="dividerSection" />

## Key Features of C++

<hr class="dividerSection" />

<div class="centeredBullet">
  <ul class="diamondBullets fullWidthBullet">
    <li>Cross-platform compatibility</li>
    <li>High performance and efficiency</li>
    <li>Object-oriented features like classes, inheritance, and polymorphism</li>
    <li>Extensive Standard Template Library (STL)</li>
    <li>Low-level memory manipulation</li>
    <li>Wide industry use in finance, embedded systems, gaming, and more</li>
  </ul>
</div>

## A Simple "Hello, World!" Program

<hr class="dividerSection" />

Here's an example of a basic C++ program that prints <span class="codeSnip">Hello, World!</span> to the console.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

<hr class="dividerExample" />

#### Example: Output

<hr class="dividerExample" />

```shell
Hello, World!
```

## Summary

<hr class="dividerSection" />

C++ remains one of the most influential programming languages, combining the efficiency and control of low-level programming with the power and abstraction of high-level programming paradigms.

Understanding C++ is an excellent foundation for any software developer interested in systems-level or performance-critical development.
